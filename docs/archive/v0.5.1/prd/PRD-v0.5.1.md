# PRD-v0.5.1：系统原生 Help 菜单增强与偏好设置「关于」信息面板

## 1. 背景与目标

在 mditor v0.5.0 顺利交付海量文档闪电检索、原生拖拽管理与出版级多格式导出后，应用已迈入成熟桌面工具阶段。

然而，在日常桌面操作与社区反馈中存在明显的软件标识信息缺失：
1. **菜单栏信息盲区**：桌面系统顶栏菜单中缺少规范的 **Help（帮助）** 菜单项，用户无法直接在菜单中查看当前安装的版本号；
2. **开源项目与作者连接断层**：缺少项目官方开源代码仓库（GitHub）链接与作者联系渠道，用户在遇到使用问题或需要贡献代码时难以快速触达；
3. **偏好设置关于面板缺失**：偏好设置模态框（`⌘,`）中仅有外观、编辑器、文件三项设置，缺少主流软件标配的「关于 (About)」展示卡片。

**v0.5.1 核心定位**：构建符合 macOS / Windows / Linux 桌面规范的**「系统原生 Help 菜单体系与偏好设置关于面板」**，清晰呈现版本号、开源项目地址与作者联络通道，提升开源软件的信噪比与归属感。

---

## 2. 用户故事

- **作为一名日常使用者**，当我点击系统顶部「Help」菜单或进入应用偏好设置时，我希望能一眼看清我正在使用的 mditor 具体版本号，以便确认我是否拥有最新特性。
- **作为开源社区开发者**，当我想要阅读源码、提交 Issue 或 Star 支持时，我希望能直接从 Help 菜单或关于面板一键跳转至 GitHub 仓库页面。
- **作为企业与新媒体内容创作者**，当我想与作者交流排版场景或反馈定制化需求时，我希望能一键调起邮件客户端直接向作者发送邮件。

## 3. 功能需求

### F38：系统原生 Help 菜单增强与偏好设置「关于」信息面板

- **AC-38.1 [系统原生 Help 菜单与核心条目]**：
  - 应用菜单中显式挂载规范的 **Help** 菜单（macOS 顶栏、Windows/Linux 原生菜单）；
  - Help 菜单中必须包含以下标准条目：
    1. **版本号**：格式为 `版本: v0.5.1`（或跟随运行时动态版本），点击呼出原生关于对话框；
    2. **项目地址**：显示 `项目地址: https://github.com/monkeychen/mditor`；
    3. **作者信息**：显示 `作者: 陈志安 (Mail: cza55007@gmail.com)`；
    4. **关于 mditor**：呼出应用原生关于对话框。

- **AC-38.2 [安全外链跳转与邮件客户端联动]**：
  - 点击「项目地址」条目，通过 Electron 主进程原生 `shell.openExternal` 在系统默认浏览器中安全打开 `https://github.com/monkeychen/mditor`；
  - 点击「作者信息」条目，自动以 `mailto:cza55007@gmail.com` 协议唤起操作系统默认邮件客户端撰写窗口；
  - 主进程建立严格的外链协议白名单检查，拦截非 `https:` / `http:` / `mailto:` 协议，防御潜在注入风险。

- **AC-38.3 [内置偏好设置「关于」交互面板]**：
  - 在偏好设置（`⌘,`）中新增第 4 个导航选项卡：**关于 (About)**；
  - 点击进入「关于」面板，呈现 macOS 风格的精致圆角卡片：
    - mditor 琥珀金精致 App Icon 徽章与产品标题；
    - 当前运行版本号标签（`v0.5.1`）；
    - 一句话产品定位标语；
    - 项目地址链接（带外链箭头图标，点击直接安全打开）；
    - 作者姓名与邮箱联系按钮（带邮件图标，点击调起邮件客户端）。

- **AC-38.4 [系统原生关于面板与对话框对齐]**：
  - macOS 平台调用 `app.setAboutPanelOptions`，对齐系统自带「关于 mditor」原生面板信息；
  - 触发关于对话框时，弹出包含产品简介、版本号、GitHub 访问按钮与邮件联系按钮的原生弹窗。
