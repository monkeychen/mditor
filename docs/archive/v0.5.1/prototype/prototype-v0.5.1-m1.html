mditor v0.5.1 体验原型

本原型演示 F38：系统原生 Help 菜单增强与偏好设置「关于」信息面板 的完整交互链路。

👉 交互指引：
1. 点击顶部菜单栏的 「Help (帮助)」，查看版本号、项目 GitHub 地址与作者邮箱菜单项；
2. 点击右上角 「偏好设置 (⌘,)」，直接进入 「关于 (About)」 选项卡预览品牌卡片；
3. 在菜单或关于面板中点击链接，将弹出真实模拟的安全外链调起提示。
