# Release Note - mditor v0.5.1：系统原生 Help 菜单重构与排版使用指南体系

mditor v0.5.1 是一个聚焦于排版辅助能力与桌面规范体验的重构增强版本。本版本全面重构了系统原生菜单中的 **Help（帮助）** 菜单，彻底收敛平铺杂乱信息，专注于提供最实用的 **Markdown 语法指南**、**Mermaid 图表指南** 与 **数学公式语法指南**，并配套交付了沉浸式交互速查组件与集中关于卡片。

---

## 1. 核心特性与变更记录 (Changelog)

### Added
- **系统原生 Help 菜单重构（Refined Help Menu，F38 / AC-38.1）**：
  - **高信噪比排版参考**：Help 菜单结构彻底优化，收录实用指南子项：
    1. **Markdown 语法指南**：直通 Markdown 标题、强调、列表、表格、代码高亮等速查；
    2. **Mermaid 图表指南**：直通流程图、时序图、类图、状态图、甘特图等常用图表速查；
    3. **数学公式语法指南**：直通 KaTeX / LaTeX 行内公式、独立公式块、微积分与矩阵符号速查；
    4. **关于 mditor**：保留系统原生「关于卡片」，集中呈现版本号、项目地址与作者信息。

- **交互式语法使用指南模态组件（Guide Modal，F38 / AC-38.2）**：
  - **沉浸式速查面板**：从 Help 菜单一键呼出，支持在 Markdown、Mermaid、数学公式三大类别间从容切换；
  - **即时复制与插入**：每个语法卡片附带精简说明与代码块，支持「一键复制」与「直接插入到当前光标所在编辑位置」；
  - **在新标签页中打开完整文档**：支持一键将当前类别语法指南生成为 Markdown 文档在编辑区打开，方便边写边学。

- **内置偏好设置「关于」面板（Preferences About Panel，F38 / AC-38.3）**：
  - **独立选项卡导航**：在偏好设置面板（`⌘,`）保留独立的「关于 (About)」选项卡；
  - **高保真品牌卡片**：展示 mditor 琥珀金精致圆角 App 徽章、当前动态版本号、产品标语定位、带外部链接图标的 GitHub 官方主页链接以及作者邮箱直达按钮；
  - **安全协议白名单**：建立主进程严格的 URL 协议过滤机制（仅允许 `https:` / `http:` / `mailto:`），防御潜在注入风险。

### Changed
- **信息呈现架构收敛**：
  - 不再在原生 Help 菜单第一级平铺罗列版本号与作者信息，版本号、开源主页与作者联络通道全部内聚于「关于卡片」与关于对话框中，菜单栏保持极致内敛。
- **全局版本号统一管理**：
  - 由全局单源常量 `APP_VERSION` 与 Electron 原生 `app.getVersion()` 统一分发，彻底消除散落硬编码与版本失步问题。
