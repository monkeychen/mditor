# PRD-v0.4.0：偏好设置面板、工作区文件管理与全能文本文档/代码高亮引擎

## 1. 版本背景与目标

在 v0.3.1 完成了数学公式、顶栏解耦、多工作区文件夹以及自动化发版矩阵加固之后，mditor 的基础排版内核与平台发布能力已趋于成熟。
当前编辑器仍停留在「单机 Markdown 写作查看」工具层面，存在三大生产力断点：
1. **排版个性化缺失**：用户无法调节字号、字体、行宽、自动保存等打字习惯偏好（无 `⌘,` 偏好设置窗口）；
2. **文件管理半闭环**：侧边栏能够浏览已添加的多文件夹，但无法在侧边栏直接新建、重命名、删除文件或在系统访达中定位；
3. **文件格式局限**：作为日常主力桌面编辑器，用户频繁需要随手打开 `.json`、`.py`、`.sql`、`.java`、`.log`、`.txt` 等文本与代码文件，当前仅支持 Markdown 格式。

**v0.4.0 核心定位**：全面升级为**兼具沉浸式 Markdown 排版与全能轻量代码/文本编辑能力的高生产力工作台**。

## 2. 功能清单（Features）

### F27：macOS 原生风格偏好设置面板（Preferences Panel，`⌘,`）
- **AC-27.1（面板唤起与层级）**：
  - 支持快捷键 `⌘,`（macOS）/ `Ctrl+,`（Win/Linux）以及菜单栏「设置 / Preferences」触发独立浮层设置面板；
  - 支持 `Esc` 键或点击遮罩关闭。
- **AC-27.2（分类配置项）**：
  - **外观（Appearance）**：默认主题选择（GitHub / 暗夜科技 / 羊皮纸 / 复古打字机）、暗黑模式开关（浅色 / 深色 / 跟随系统）；
  - **编辑器（Editor）**：
    - 正文字体族（系统默认 SF Pro、苹方、无衬线字体等）；
    - 正文字号选择（13px、14px、15px、16px、18px、20px）；
    - 正文最大宽度限制（自适应 / 720px / 860px 经典 / 1024px / 100% 全宽）；
    - 行高比例（1.5 / 1.6 / 1.8）；
    - 代码块字体（系统等宽字体、JetBrains Mono、Fira Code、SF Mono）；
  - **文件与保存（Files）**：
    - 自动保存开关与间隔（关闭 / 实时保存 / 1秒 / 5秒 / 30秒）；
    - 启动时恢复上一次打开的文件与工作区文件夹。
- **AC-27.3（即时热更新与持久化）**：
  - 任何配置项修改后，立即通过 DOM CSS 变量注入生效，无需重启应用；
  - 自动持久化存储至 `localStorage`（主进程可通过配置文件持久化）。

### F28：工作区文件夹右键上下文管理与跨平台适配（Workspace Context Menu - macOS / Windows / Linux）
- **AC-28.1（文件夹与目录项上下文菜单）**：
  - 在侧边栏已添加的文件夹根目录或子目录上右键点击，弹出原生风格上下文菜单：
    - **新建文件 (New File)**：原地呼出内联输入框，输入文件名并回车（默认 `.md`，支持自定义扩展名如 `.json`、`.py`），立即在对应目录下创建文件并在新标签页中打开；
    - **新建文件夹 (New Folder)**：在当前目录下创建子目录；
    - **在系统文件管理器中显示 (Reveal in System File Manager)**：
      - macOS 平台文案为 **「在访达中显示 (Reveal in Finder)」**；
      - Windows 平台文案为 **「在文件资源管理器中显示 (Show in File Explorer)」**；
      - Linux 平台文案为 **「在文件管理器中显示 (Open in File Manager)」**；
      - 底层统一通过 Electron `shell.showItemInFolder` 跨平台 API 直接唤起操作系统原生文件管理器并精确定位；
    - **从侧边栏移除 (Remove from Workspace)**：从工作区解绑，严格保留本地磁盘真实文件。
- **AC-28.2（文件项上下文菜单与回收站安全删除）**：
  - 在侧边栏文件项上右键点击：
    - **重命名 (Rename)**：原地变为内联可编辑输入框，失焦或回车完成重命名，若该文件已打开则自动同步 Tab 标题与文件路径；
    - **安全移入废纸篓 / 回收站 (Move to Trash / Recycle Bin)**：
      - macOS / Linux 文案为 **「移到废纸篓」**；Windows 文案为 **「移到回收站」**；
      - 底层严格调用 Electron `shell.trashItem` 原生操作系统能力，在 Windows 走回收站回收、在 macOS 走废纸篓、在 Linux 遵循 freedesktop.org Trash 规范，**严禁使用 `fs.unlink` 硬删除**；若被删除文件正在打开则自动关闭对应标签页；
    - **在系统文件管理器中显示 (Reveal in Finder / Explorer)**；
    - **复制路径 (Copy Path)**：复制绝对路径（`Copy Path`）或相对工作区路径（`Copy Relative Path`）。
- **AC-28.3（跨平台快捷键与文件名校验门禁）**：
  - **快捷键平台自适应**：
    - macOS：新建 `⌘N`、重命名 `Enter`、移入废纸篓 `⌘⌫`、复制路径 `⌥⌘C`；
    - Windows / Linux：新建 `Ctrl+N`、重命名 `F2`、移入回收站 `Delete`、复制路径 `Ctrl+Shift+C`；
  - **文件名合法性校验**：
    - 针对 Windows 系统自动防御非法字符（`\ / : * ? " < > |`）及保留名（`CON`, `PRN`, `AUX`, `NUL` 等），输入非法字符时给予轻量友好 Toast 提示阻断，防止写入崩溃；
    - 自动适配跨平台路径分隔符（Windows 反斜杠 `\` 与 Unix 斜杠 `/` 自动归一化处理）。

### F29：全能轻量文本文档与主流编程语言代码渲染高亮引擎（Universal Text & Code Engine）
- **AC-29.1（全面扩展支持的文件格式池）**：
  - 侧边栏文件扫描（`scanMarkdownDirectory` 扩展为 `scanDirectoryTree`）与打开文件对话框（`dialog.showOpenDialog`）全面解除仅限 `.md` 的限制；
  - **支持的文件扩展名池**：
    - **Markdown 类**：`.md`、`.markdown`、`.mdown`
    - **普通文本与日志**：`.txt`、`.text`、`.log`、`.diff`、`.patch`
    - **数据交换与配置**：`.json`、`.jsonc`、`.yaml`、`.yml`、`.toml`、`.xml`、`.ini`、`.env`、`.csv`、`.properties`
    - **Web 与前端**：`.html`、`.htm`、`.css`、`.scss`、`.less`、`.js`、`.jsx`、`.ts`、`.tsx`、`.mjs`、`.cjs`
    - **通用编程语言**：
      - Python (`.py`, `.pyw`)
      - SQL (`.sql`)
      - Java (`.java`, `.kt`)
      - Go (`.go`)
      - Rust (`.rs`)
      - C / C++ (`.c`, `.cpp`, `.h`, `.hpp`, `.cc`)
      - C# (`.cs`)
      - Shell (`.sh`, `.bash`, `.zsh`)
      - Docker / Config (`.dockerfile`, `Dockerfile`)
- **AC-29.2（智能模式路由 Smart Mode Routing）**：
  - 当打开的是 Markdown 文件（`.md`, `.markdown`）时：保持默认**双模式机制**（默认所见即所得 WYSIWYG，支持 `⌘/` 切到源码模式）；
  - 当打开的是代码或数据文件（如 `.py`, `.json`, `.sql`, `.java`, `.log`, `.txt` 等）时：
    - **自动锁定切入 CodeMirror 6 源码模式**；
    - 状态栏与工具栏的「实时渲染 / 源码模式」切换按钮根据文件类型智能禁用并提示「代码文件仅支持源码模式」；
    - 状态栏展示当前文件的语言类型（如 `Python`、`JSON`、`SQL`）及行号列号。
- **AC-29.3（高精语法着色与代码体验）**：
  - CodeMirror 6 动态解析扩展名并调用 `@codemirror/language-data` 挂载对应语言包；
  - 默认展示行号、支持括号匹配、代码折叠与当前行高亮；
  - 针对 `.txt` 与 `.log` 文件，提供整洁的等宽排版与平滑滚动。

## 4. 非目标（v0.4.0 暂不包含）

1. 云端 Git / SVN 版本控制树集成（仅做本地文件系统交互）；
2. 完整语言服务器协议（LSP 代码补全、重构、跳转定义，mditor 定位为沉浸式写作与轻量代码编辑器，非大型 IDE）；
3. 任何侵犯 Typora 商标、内置 CSS 的行为（严格遵守 `GEMINI.md` 红线）。
