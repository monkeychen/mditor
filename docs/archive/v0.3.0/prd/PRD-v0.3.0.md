# PRD-v0.3.0：专业级科学排版、矢量图表与多主题系统

## 1. 背景与目标

- **版本定位**：在 v0.2.0 已建立的「Milkdown 所见即所得 + CodeMirror 6 纯源码」高保真双模式底座之上，进一步补齐 Typora 最受专业知识工作者、技术研发人员和学术研究者青睐的核心高级表达能力：**数学公式（KaTeX）**、**Mermaid 流程图表**、**扩展排版语法（高亮/脚注/TOC/上下标）**与**经典多主题视觉系统**。
- **与上版本关系**：v0.2.0 解决了基础排版跳变、表格/列表/图片等块级结构的原生编辑体验，源文件保真门禁已建立。v0.3.0 在此架构上扩展 AST 节点与渲染器，保持源语法 100% 纯文本保真与流畅打字手感。
- **技术决策原则**：
  - **数学公式引擎**：选择 **KaTeX** 而非 MathJax。
    - *为什么*：KaTeX 渲染速度是 MathJax 的 10 倍以上，无运行时依赖，同步纯 CSS 渲染，输入公式时无肉眼可见的排版跳闪。
    - *对用户的影响*：实时敲入 LaTeX 表达式即时上屏，长公式文档滚动丝滑不卡顿。
  - **Mermaid 渲染沙箱化**：采用异步轻量 SVG 渲染，内嵌防爆盾捕获语法异常。
    - *为什么*：Mermaid 语法编写过程中必然存在短暂的中间不完整态。
    - *对用户的影响*：用户输入未闭合的语法时仅提示行内提示条，绝不白屏或崩溃整个编辑器。
  - **主题切换系统**：纯 CSS 变量（CSS Custom Properties）架构。
    - *为什么*：无需重载 DOM 或重建编辑器实例，切换主题为 0ms 瞬间样式重算。
    - *对用户的影响*：夜间模式或护眼模式一键切换，编辑光标位置与滚动条绝对不丢失。

## 2. 用户故事

- **US1**：As an 学术/算法工程师，I want 在行内直接键入 `$f(x) = \sigma(Wx+b)$` 或键入 `$$` 插入独立公式块，So that 我能在流畅书写的同时看到精美规范的数学公式渲染，并在点击时实时编辑 LaTeX 源码。
- **US2**：As a 系统架构师/技术写作者，I want 在代码块中输入 ```` ```mermaid ```` 并编写流程图或时序图，So that 我无需在第三方绘图工具中画图截屏，直接在文档中生成清晰的矢量图表并支持复制/导出。
- **US3**：As a 笔记沉浸写作者，I want 使用 `==高亮==` 重点标记文本、输入 `[^1]` 快速引用脚注、在文首使用 `[TOC]` 自动生成带跳转的目录块，So that 我的知识文档结构更加立体和易于检索。
- **US4**：As an 夜间或长时间专注阅读写作者，I want 在 macOS Light、GitHub、Night（暗黑）、Newsprint（暖色纸张）等多款经典主题间自由切换，So that 我的眼睛在不同光线环境下都能保持舒适。

## 3. 功能需求与验收标准

### F19：数学公式系统（KaTeX）

1. **行内公式（Inline Math）**：
   - 语法：`$formula$`。
   - 行为：非光标状态下渲染为专业 LaTeX 数学排版；光标进入时局部露出两侧 `$` 定界符并允许编辑公式源码；光标移出后立即根据最新公式刷新渲染。
2. **块级公式（Block Math）**：
   - 语法：输入 `$$` + 回车，或在段落输入：
     ```markdown
     $$
     \int_{-\infty}^{+\infty} e^{-x^2} dx = \sqrt{\pi}
     $$
     ```
   - 行为：独立居中块级排版；提供公式交互容器，支持点击切换源码编辑视图/渲染视图；语法错误时给出友好微提示，不中断后续排版。
3. **快捷键**：`⌥⌘M` 快速包裹选区为行内公式或插入空公式。

**验收标准（AC）**：
- **AC-19.1**：打开包含复杂行内公式与独立矩阵/微积分公式块的文档，KaTeX 均正常渲染为矢量公式符号（DOM 存在 `.katex` 结构）。
- **AC-19.2**：光标移动到行内公式内部时，露出 LaTeX 源码；在源码中追加字符后光标离开，公式渲染结果立即同步更新。
- **AC-19.3**：在源码模式下查看，底层 Markdown 依然为标准 `$formula$` 与 `$$...$$`，打开/保存保真度 100%。

### F20：Mermaid 矢量图表实时渲染

1. **支持图表类型**：
   - 流程图（Flowchart）
   - 时序图（Sequence Diagram）
   - 类图（Class Diagram）
   - 状态图（State Diagram）
   - 甘特图（Gantt）
   - 实体关系图（ER Diagram）
2. **交互行为**：
   - 围栏代码块语言指定为 `mermaid` 时，实时渲染模式下转换为交互式图表容器。
   - 容器右上角提供：**「查看源码/编辑」**、**「复制 Mermaid 源码」**、**「导出为 PNG/SVG」**。
   - 语法有误时显示半透明错误指示条，不遮挡正文。

**验收标准（AC）**：
- **AC-20.1**：包含标准流程图 `graph TD; A-->B;` 的文档加载后，DOM 中生成可缩放的 SVG 节点。
- **AC-20.2**：点击图表工具栏上的「编辑」按钮，展开内嵌源码输入区，修改图表连线后 SVG 实时无损更新。
- **AC-20.3**：若输入非法语法（如 `graph TD; A---` 未闭合），捕获错误并显示行内轻提示，编辑器正常可用不崩溃。

### F21：Typora 风格扩展排版语法

1. **高亮标记（Highlight）**：
   - 语法：`==高亮内容==`。
   - 行为：渲染为亮黄色内联背景，光标进入时露出 `==`，移出后隐藏。
2. **脚注系统（Footnote）**：
   - 语法：正文中 `[^1]` 或 `[^note]`，文档底部 `[^1]: 详细注释内容`。
   - 行为：正文处生成上标悬浮序号，点击平滑滚动到底部注释；底部注释处提供返回跳转按钮。
3. **上标与下标（Superscript & Subscript）**：
   - 语法：`H~2~O` 渲染为下标，`X^2^` 渲染为上标。
4. **自动目录块（`[TOC]`）**：
   - 语法：单行输入 `[TOC]` 或 `[toc]` + 回车。
   - 行为：自动在当前位置生成与正文 H1–H6 树形结构一致的可点击目录列表；当正文增删修改标题时，目录块实时自动联动刷新。
5. **YAML Front Matter**：
   - 语法：文档开头由 `---` 包裹的键值对。
   - 行为：渲染为精致的折叠元数据卡片，支持展开编辑与收起隐藏。

**验收标准（AC）**：
- **AC-21.1**：`==重要文字==` 渲染带有高亮样式（`background-color: rgba(254, 240, 138, ...)`）。
- **AC-21.2**：输入 `[TOC]` 后自动生成全文档章节目录，点击目录项即时跳转到对应正文位置。
- **AC-21.3**：文档含 `[^1]` 时，在阅读模式下鼠标悬停可浮动预览对应注释文本。
- **AC-21.4**：以上扩展语法在切换至源码模式时完全保真，不丢失特殊标记符。

### F22：经典多主题视觉系统

1. **内置主题方案**：
   - **macOS Light**：macOS 默认现代简约风格（白底、深灰文字、柔和蓝色点缀）。
   - **GitHub**：对标 GitHub 官方文档风格（高对比、标准衬线/无衬线排版）。
   - **Night（深色模式）**：对标 Typora 经典暗色主题（深炭黑背景 `#1E1E1E`、柔和白色文字、暗色代码块与表格）。
   - **Newsprint（报纸/羊皮纸）**：温润护眼米黄色底（`#F6F3ED`），衬线字体风格。
2. **交互入口与记忆**：
   - 顶部菜单「视图 -> 主题」与底部状态栏提供主题选择器。
   - 主题偏好自动持久化保存到本地配置，下次启动自动恢复。

**验收标准（AC）**：
- **AC-22.1**：切换为「Night」主题后，主背景变为深色，正文字符自动变为浅灰白，对比度符合 WCAG AA 标准。
- **AC-22.2**：切换主题时编辑器状态（光标位置、滚动距离、撤销重做栈）100% 保持，耗时 ≤ 50ms。
- **AC-22.3**：重启应用或新建标签页后，继承已选择的主题配置。
