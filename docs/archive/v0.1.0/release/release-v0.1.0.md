# release-v0.1.0: 跨平台 macOS 质感沉浸式 Markdown 编辑器 (mditor)

## 1. 版本内容摘要
mditor v0.1.0 是首个功能完整的跨平台桌面 Markdown 编辑器。它结合了 macOS 极简无边框设计与 CodeMirror 6 纯文本高性能实时预览内核（光标入行即编辑，移开即渲染），提供多标签页管理、截图/拖拽图片自动落盘到 `./assets/`、目录大纲双向联动、悬浮查找替换，以及一键复制为微信公众号/知乎排版和多格式导出。

---

## 2. 变更记录 (Changelog)

### Added
- **macOS 沉浸式窗口与多标签页系统**：
  - 隐藏原生标题栏（`hiddenInset` 交通灯完美避让）；
  - 多标签页管理（Tabs），支持未保存状态小圆点、关闭未保存文档模态阻断确认；
  - 快捷键体系：`⌘T`（新建标签）、`⌘W`（关闭标签）、`⌘1..9`（直达标签）、`⌘⇧[`/`⌘⇧]`（左右轮换）。
- **CodeMirror 6 驱动的即时所见即所得实时预览（Live Preview）**：
  - 1-6 级标题离开隐藏 `#` 前缀并以大号排版渲染，光标移入平滑展开；
  - 加粗、斜体、删除线、行内代码语法离开隐匿定界符；
  - 引用块优雅竖线引导，分割线横向平滑收缩；
  - 交互式任务列表复选框（`- [ ]` / `- [x]`），支持直接鼠标点击切换。
- **高级代码块高亮与复制**：
  - 围栏代码块（```lang）深色卡片渲染，顶部展示语言标识标签与一键复制代码按钮。
- **本地图片自动落盘管道**：
  - 截图粘贴（`⌘V`）或文件拖拽，系统自动在当前文档同级创建 `./assets/` 目录并将图片写盘；
  - 光标处自动插入相对路径 Markdown 语法；
  - 编辑器内提供内嵌图片自适应卡片实时渲染。
- **文档结构大纲（Outline / TOC）抽屉导航**：
  - 自动提取 H1-H6 标题层级；
  - 快捷键 `⌘⇧O` 展开/折叠 240px 左侧大纲抽屉；
  - 点击大纲项实现 CodeMirror 6 平滑滚动跳转与光标精准定位。
- **快捷查找与替换（Search & Replace）**：
  - `⌘F` 唤起悬浮搜索胶囊，实时显示匹配序号（如 `1/3`）；
  - `⌘H` 展开替换面板，支持单个替换与全量一键替换。
- **多格式导出与微信公众号排版引擎**：
  - 一键将 Markdown 转为带 Inline CSS 的富文本 HTML 写入系统剪贴板（`text/html`），微信公众平台、知乎后台直接 `⌘V` 粘贴格式无损；
  - 导出单文件自包含 HTML（样式打包内嵌，离线可用）；
  - 调用 Chromium 打印管道导出规范分页矢量 PDF。

## 3. 交付物清单与获取方式

### 运行环境要求
- Node.js >= 20.0.0 (推荐 v22+ 或 v24)
- macOS (arm64/x64) / Windows / Linux

### 获取与启动
```bash
git clone git@github.com:monkeychen/mditor.git
cd mditor
npm install
npm run dev        # 启动桌面开发版
npm run build      # 打包构建 production 产物
npm run test:all   # 执行全量自动化测试（Vitest + Playwright）
```
