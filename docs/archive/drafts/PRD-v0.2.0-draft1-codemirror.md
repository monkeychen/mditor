# PRD-v0.2.0: 沉浸式真所见即所得（Typora 体验）与全语法排版渲染引擎

## 1. 背景与目标

### 1.1 背景与用户痛点
在 v0.1.0 实际真机体验中，暴露了严重的渲染与交互问题：
1. **排版跳变感极差（Jitter / FOUC）**：之前实现的 Hybrid 机制在光标移入行时粗暴将整行退化回 14px 纯源码，导致打字时字号和行高剧烈跳变，严重破坏沉浸感；
2. **核心语法渲染大面积缺失**：GFM 表格完全以纯文本显示、普通列表无缩进无圆点符号、引用块缺乏容器化美感、图片在部分路径下加载失效；
3. **缺少模式隔离**：用户在需要专注排版写作与需要精确微调 Markdown 源码之间缺少明确的模式切换通道。

### 1.2 核心目标
重构编辑器交互与渲染内核，深度对齐 **Typora 标杆体验**：
- **默认真所见即所得（Live Mode）**：光标在行内输入时保持大号排版与视觉样式，彻底杜绝跳变；
- **纯源码模式（Source Code Mode）**：支持一键（快捷键 `⌘/`）切换为 VS Code 风格的干净纯 Markdown 源码；
- **全语法高级渲染**：提供高交互性 GFM 表格卡片、多级缩进富列表、优雅容器化引用块及健壮的图片渲染。

---

## 2. 用户故事

- **As a 创作者**，我希望在标题、列表和粗体中输入文字时，文字始终保持优雅的排版尺寸而不是瞬间退化为小号代码，以便体验原生级的沉浸打字心流。
- **As a 知识工作者**，我希望在 Markdown 中直接看到并编辑漂亮的表格（支持 Tab 键跳转下一个单元格），而不是面对难以对齐的 `|---|---|` 字符。
- **As a 极客与技术人员**，我希望在需要排查语法或批量修改时，能按下 `⌘/` 瞬间切换到纯源码模式，精准掌控每一个字符。

## 3. 功能需求与验收标准 (F / AC)

### F11: Typora 风格双模式切换系统 (Mode Switcher)
- **F11.1**: 系统支持两种互斥的编辑工作模式：
  1. **实时渲染模式（Live Mode / WYSIWYG）**（默认激活）：隐藏定界符并完整渲染富排版。
  2. **源代码模式（Source Mode）**：全文本纯源码显示，无任何隐藏与 Widget 替换，展示单宽字体与行号。
- **F11.2**: 交互与快捷键通道：
  - 支持全局快捷键 `⌘/`（Windows/Linux 为 `Ctrl+/`）在两模式间毫秒级无缝切换；
  - 窗口底部状态栏右侧常驻模式切换按钮，清晰展示「🎨 实时渲染」或「📝 源代码」，点击即可切换。
- **验收标准 (AC)**：
  - **AC-11.1**: 按下 `⌘/` 能在 Live Mode 与 Source Mode 之间即时切换，文档内容与光标选区位置精确保持不变。
  - **AC-11.2**: 在 Source Mode 下，所有 Markdown 字符（`#`, `**`, `|`, `>`）100% 原始显露，不渲染任何装饰性组件。
  - **AC-11.3**: 状态栏指示器准确反映当前模式，点击可切换。

### F12: 零跳动真所见即所得输入引擎 (Jitter-Free In-Place Editing)
- **F12.1**: 光标置于标题行时，标题依然维持 H1(28px) / H2(22px) / H3(18px) 的原生大号字重与排版尺寸，仅在光标紧贴 `#` 前缀时以淡色半透明辅助展示，绝不允许整行字体缩小突变。
- **F12.2**: 行内加粗（`**`）、斜体（`*`）、删除线（`~~`）在光标位于内部时维持加粗/倾斜效果，仅按需微露定界符，排版位置不剧烈抖动。
- **验收标准 (AC)**：
  - **AC-12.1**: 光标移入或移出 H1~H6 标题行时，文字行高（line-height）与字号（font-size）变化率小于 5%，消除视觉跳跃。
  - **AC-12.2**: 在加粗文本中连续打字，文字立即以 Bold 样式跟手呈现。

### F13: GFM 交互式表格渲染引擎 (Interactive TableWidget)
- **F13.1**: 自动检测标准 Markdown 表格语法（`| ... |`），在 Live Mode 下用现代 macOS 质感 HTML `<table>` Widget 进行块级替换。
- **F13.2**: 表格具备单元格直接编辑能力，支持按 `Tab` 跳至下一单元格，按 `Shift+Tab` 跳至上一单元格，末尾单元格按 `Tab` 自动新增一行。
- **F13.3**: 单元格内容的修改实时双向同步至底层 Markdown 源文本（自动维护管道符与对齐空格）。
- **验收标准 (AC)**：
  - **AC-13.1**: 包含表头与分隔符的 Markdown 表格在 Live Mode 下自动渲染为圆角微边框的现代表格。
  - **AC-13.2**: 在表格单元格中输入内容，切换至 Source Mode 可见底层 Markdown 源码正确更新且格式规范。
  - **AC-13.3**: 在单元格内按 `Tab` 能顺序将光标推进至下一个单元格。

### F14: 智能富列表与自动排版 (Rich List Engine)
- **F14.1**: 无序列表（`- `, `* `, `+ `）自动隐藏前缀破折号，替换为雅致的 macOS 灰黑色圆点（Bullet）。
- **F14.2**: 有序列表（`1. `, `2. `）替换为规范对齐的排版数字。
- **F14.3**: 列表输入增强：在列表项末尾回车，下一行自动生成同级列表项；连续两次回车或回退键自动退出列表模式；支持 `Tab` 键向右增加缩进层级、`Shift+Tab` 向左减少缩进。
- **验收标准 (AC)**：
  - **AC-14.1**: Live Mode 下普通列表项均具有统一的左悬挂缩进和高质感圆点符号。
  - **AC-14.2**: 在末尾按回车能自动补全下一行列表符号。
  - **AC-14.3**: 按 `Tab` / `Shift+Tab` 能对列表项实施嵌套缩进。

### F15: 容器化引用块渲染 (Containerized Blockquote)
- **F15.1**: 连续多行引用语法（`> ...`）统一聚合渲染为一个完整的卡片容器。
- **F15.2**: 引用容器左侧具有 3px 主题 Accent 竖线，内衬柔和微灰背景（`#F4F1EA` / `#2C2A29`）与斜体字效，隐藏行首丑陋的 `>` 符号。
- **验收标准 (AC)**：
  - **AC-15.1**: 多行连续引用在 Live Mode 下渲染为连贯的一体化卡片容器。
  - **AC-15.2**: 光标置于引用块内打字不破坏容器外观。

### F16: 全场景图片渲染增强 (Robust Image Rendering)
- **F16.1**: 图片渲染管道全量兼容支持：
  1. 当前文档同级相对路径（如 `./assets/pic.png`）；
  2. 操作系统本地绝对路径（如 `file:///...` 或 `/Users/...`）；
  3. 网络 HTTP / HTTPS 图片链接（如 `https://example.com/pic.png`）。
- **F16.2**: 增强容错与交互：加载中提供微闪骨架屏、加载失败提供优雅的「图片加载失败」占位卡片；点击图片支持悬浮展示 Alt 信息与尺寸调整。
- **验收标准 (AC)**：
  - **AC-16.1**: 本地相对路径、绝对路径及网络图片在 Live Mode 下均可正确展示图像。
  - **AC-16.2**: 遇到无效图片链接时展示规范的错误占位卡片，杜绝页面破损或报错。

## 5. 非目标 (Out of Scope for v0.2.0)

1. **富文本拖拽排版重排**：本版保持 Markdown 纯文本真实性，不引入复杂的外部富文本拖拽排版框架；
2. **多用户协同编辑（CRDT）**：本版坚持本地优先单机极速原则，不涉及云端协同；
3. **数学公式 KaTeX 与 Mermaid 渲染**：规划放至 v0.3.0，保持本版专注于核心 Markdown 文本排版手感。
