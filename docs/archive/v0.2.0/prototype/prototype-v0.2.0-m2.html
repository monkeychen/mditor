💡 M2 交互体验指引（全面对标 Typora）

1. 表格 (TableWidget)：点击下方任意单元格即可激活并唤出顶部的胶囊工具栏；在表格最后一行最后一格按 Tab 会自动在末尾追加新行！

2. 代码块 (CodeBlockWidget)：右上角带有语言标识与一键「复制代码」动效反馈按钮。

3. 多源图片 (ImageWidget)：支持相对/网络图片，鼠标悬停时轻微显露源码浮层，路径缺失时提供精致占位卡片。
