# 设计第一性原理与 Typora 级交互手感
 
用户体验是所有产品的最高准则。**后端可以很复杂，但用户触碰到的每一层必须丝滑。** 在 mditor v0.2.0 中，我们坚决废除光标进入整行退化缩小的糟糕设计，带来纯正的所见即所得。
 
## 核心交互设计与排版体验
 
> 系统承担复杂性：能自动化的不手动，能推断的不让用户填，能一步完成的不拆成三步。光标在引用块内部打字时，容器结构保持完整。
 
- **真所见即所得**：标题、加粗与斜体在打字时排版尺寸完全恒定，字号零跳动
- **Markdown 语法即时触发**：键入 `## ` 自动变标题，键入 `- ` 自动变列表
- **双模式互通**：随时按 ⌘/ 切换为纯源码模式，精准掌控每一个字节
 
- [x] 接入 Milkdown (ProseMirror + remark) 块模型内核
- [x] 实现标题与粗体输入零跳变（Jitter-Free）
- [ ] M2: 交互式 GFM 表格与全功能图片卡片
