# Spec-v0.3.0-M2：Mermaid 流程图与图表系统

## 1. 目标与范围

- **覆盖功能**：PRD-v0.3.0 中的 F20（Mermaid 图表系统）全部验收标准（AC-20.1 ~ AC-20.3）。
- **交付内容**：
  1. 引入 `mermaid` 图表渲染引擎并在主入口安全集成；
  2. 实现 `code_block` 语言为 `mermaid` 时的专业图表卡片渲染（流程图、时序图、甘特图、类图等直接渲染为自适应矢量 SVG）；
  3. 实现浮动工具栏与双态切换：**「查看/编辑源码」**、**「复制源码」**、**「导出为 SVG/PNG」**；
  4. 实现语法容错兜底：输入非法或未闭合语法时展示温和警告指示条，保留源码编辑入口，确保编辑器稳定可用不白屏；
  5. 保持 Markdown 源文件 100% 逐字节保真，确保「打开 ➔ 矢量图表渲染 ➔ 源码修改 ➔ 存盘」无损还原。

---

## 2. 架构与技术设计

### 2.1 依赖选型与引入

| 依赖库 | 作用与决策理由 | 对用户的影响 |
|---|---|---|
| `mermaid` | 开源事实标准的纯前端文本绘图引擎，支持流程图、时序图、状态图、甘特图等完整语法族 | 用户可以用简单的 Markdown 文本直观画出架构图和流程图，无需离开编辑器打开外部绘图工具 |

### 2.2 节点与交互设计

```
[Mermaid 图表平时状态]
╭──────────────────────────────────────────────────────────╮
│ 📊 Mermaid 图表                  [编辑源码] [复制代码] [导出]│
│                                                          │
│        ╭───────╮          ╭──────────╮                   │
│        │ 客户端 │ ───────> │  网关服务 │                   │
│        ╰───────╯          ╰──────────╯                   │
│                                 │                        │
│                                 v                        │
│                           ╭──────────╮                   │
│                           │ 核心业务集群│                  │
│                           ╰──────────╯                   │
╰──────────────────────────────────────────────────────────╯

[点击「编辑源码」后展开抽屉]
╭──────────────────────────────────────────────────────────╮
│ 📐 Mermaid 源码 (实时重绘)                     [收起 ✕]   │
│ ┌──────────────────────────────────────────────────────┐ │
│ │ graph TD                                             │ │
│ │   A[客户端] --> B[网关服务]                           │ │
│ │   B --> C[核心业务集群]                              │ │
│ └──────────────────────────────────────────────────────┘ │
│                                                          │
│ 实时预览区：                                              │
│ [即时更新的高清 SVG 矢量排版]                             │
╰──────────────────────────────────────────────────────────╯
```

1. **图表卡片容器**：
   - 当 `code_block` 节点的 `language` 属性为 `mermaid` 时，渲染为高级 macOS 风格图表卡片；
   - 居中自适应布局，背景淡雅，带轻量边框与微弱柔和阴影，图表缩放适应当前页面宽度。
2. **源码编辑与实时预览**：
   - 默认隐藏源码，呈现纯净排版；
   - 点击右上角「编辑源码」展开抽屉编辑区，打字输入时经节流/防抖（150ms）异步重绘 SVG，实现所见即所得。
3. **语法容错机制（Fault Tolerance）**：
   - `mermaid.render` 在语法错误时抛出异常；通过 `try / catch` 统一捕获，图表区呈现琥珀色语法提示框（如 `语法解析提示: Parse error on line X`），源码区依然可编辑纠错，绝不抛出未捕获异常或引起崩溃。
4. **一键复制与导出**：
   - 「复制代码」：将底层 Mermaid 文本写入系统剪贴板；
   - 「导出为 SVG」：提取当前渲染好的 `<svg>` 节点字符串，支持复制或直接保存为矢量图。
