# spec-v0.5.1-m1：系统原生 Help 菜单增强、关于面板与 TabBar 智能悬停提示设计

## 1. 里程碑目标与覆盖范围

本里程碑目标是为 mditor 补齐专业桌面软件标配的系统菜单与开源项目标识体系，并升级 TabBar 悬停信息感知能力，覆盖 PRD-v0.5.1 的全部功能点：
- **F38：系统原生 Help 菜单增强与偏好设置「关于」信息面板**
  - **AC-38.1**：应用菜单中挂载 Help 菜单，包含 Markdown/Mermaid/公式三大使用指南与原生关于选项；
  - **AC-38.2**：语法速查交互组件（Guide Modal）与代码插入联动；
  - **AC-38.3**：偏好设置模态框中新增「关于 (About)」选项卡并展示品牌卡片；
  - **AC-38.4**：macOS 系统原生关于面板与安全外链桥接。
- **F39：TabBar 标签页悬停智能感知提示（Tab Tooltip & Unsaved Title Detection）**
  - **AC-39.1**：已保存文档（具有 `filePath`）鼠标悬停在 Tab 上时提示完整绝对物理路径；
  - **AC-39.2**：未保存新建文档（`filePath` 为空）悬停时智能解析并提取正文第一行有效标题（剥离 Markdown 标题标记，跳过空行）；
  - **AC-39.3**：正文为空或无有效内容时优雅回退为标签文件名（如 `Untitled.md`）；
  - **AC-39.4**：全 Tab 项容器区域无缝平滑触发系统原生 Tooltip，保持零额外 DOM 损耗与轻量丝滑。

## 2. 关键功能设计思路

### 2.1 系统原生应用菜单构建引擎 (`src/main/menuService.ts`)

1. **菜单层次模型**：
   - macOS 场景注入专属 App Menu（包含应用名、关于、偏好设置快捷键 `⌘,`、服务、隐藏、退出）；
   - 跨平台标准挂载「文件 (File)」、「编辑 (Edit)」、「视图 (View)」、「窗口 (Window)」以及核心 **「Help (帮助)」**；
2. **Help 菜单项设计（高信噪比收敛）**：
   - 条目一：`Markdown 语法指南`，点击通知渲染进程打开语法速查模态框并切至 Markdown 视图；
   - 条目二：`Mermaid 图表指南`，点击通知渲染进程打开 Mermaid 图表语法速查；
   - 条目三：`数学公式语法指南`，点击通知渲染进程打开 KaTeX / LaTeX 公式语法速查；
   - 分割线；
   - 条目四：`关于 mditor`，展示详尽原生关于信息卡片（集中呈现版本号、项目地址与作者信息）。

### 2.2 语法速查与使用指南组件 (`src/renderer/components/GuideModal.tsx`)

1. **多维排版速查**：
   - Markdown 语法：涵盖标题层级、粗斜删高亮、上下标、列表与任务项、引用、代码高亮、GFM 表格、脚注与链接；
   - Mermaid 图表：涵盖流程图、时序图、类图、状态图、饼图、Git 分支图等主流模板；
   - 数学公式：涵盖行内/独立公式、上下标根号、微积分求和、矩阵、分段函数与希腊字母运算符；
2. **沉浸式交互能力**：
   - 支持一键复制代码片段至剪贴板；
   - 支持直接将语法示例插入当前正文文档光标处；
   - 支持「在新标签页中打开完整文档」供全屏实验与对照。

### 2.3 安全外链与主进程桥接 (`src/main/index.ts` / `src/preload/index.ts`)

1. **协议白名单机制**：
   - 仅放行以 `https://`、`http://`、`mailto:` 开头的外部 URL，任何其他协议或非法字符均被安全防御拦截；
2. **IPC 双向通信**：
   - `shell:openExternal`：供渲染进程与偏好设置关于页调用；
   - `menu:trigger`：支持原生菜单直接触发渲染进程的 `'new'`、`'open'`、`'save'`、`'saveAs'`、`'preferences'` 以及 `'guide:markdown'`、`'guide:mermaid'`、`'guide:math'` 动作。

### 2.4 偏好设置「关于」选项卡 (`src/renderer/components/PreferencesModal.tsx`)

1. **统一版本管理**：
   - 共享全局常量 `APP_VERSION = '0.5.1'`，关于页动态展示，杜绝硬编码失步；
2. **macOS 风格卡片视觉**：
   - 顶部展现琥珀金圆角 App 徽章与产品标题标语；
   - 中间呈现当前版本、项目地址（带 ExternalLink 标识）与作者信息（带 Mail 按钮）；
   - 底部明示 Local-first 原则与开源许可证。

### 2.5 TabBar 智能悬停提示与正文首行标题提取引擎 (`src/renderer/components/TabBar.tsx`)

1. **悬停提示计算逻辑 (`getTabTooltip(tab: TabItem): string`)**：
   - **分支 1（已保存物理文件）**：若 `tab.filePath` 非空，直接返回该文件的完整绝对路径（如 `/Users/chenzhian/workspace/docs/guide.md`）；
   - **分支 2（新建未保存文档）**：若 `tab.filePath` 为空（新建未持久化到磁盘），从 `tab.content` 中提取标题：
     - 按换行符（`\r?\n`）切分，过滤并找到首个非空行（去除首尾空白字符）；
     - 若该行包含 Markdown 标题标记（如 `# `、`## ` 直至 `###### `），使用正则 `^#{1,6}\s+(.+)$` 提取文本主体；
     - 若包含 Markdown 行内加粗、斜体或行内代码标记，清理格式符号得到纯净可读文本；
     - 若提取到的标题非空，返回该标题文本；
   - **分支 3（空白文档回退）**：若文档正文完全为空或全为空白符，优雅回退返回当前标签名称 `tab.fileName`（如 `Untitled.md`）。
2. **DOM 事件与可访问性挂载**：
   - 将计算得到的 `tooltip` 同时挂载在 Tab 项最外层容器元素（`<div className="tab-item ...">`）和文件名标签节点（`<span className="truncate ...">`）的 `title` 属性上；
   - 状态点（未保存/已保存）保留各自专属轻量说明（`title="未保存修改"` / `title="已保存"`）；
   - 关闭按钮保留其独立操作提示（`title="关闭 (Cmd+W)"`），形成层次分明、互不干扰的提示矩阵。

## 3. 关键技术决策

| 决策点 | 选定方案 | 为什么这么选 | 对用户的影响 |
|---|---|---|---|
| **悬停提示实现机制** | 原生 HTML `title` 属性，挂载于 TabItem 容器 | 无需注入复杂自定义 Tooltip 悬浮层或管理全局 Portal，零重绘负担、零内存泄漏风险，天然与操作系统桌面窗口管理与读屏器无障碍集成。 | 丝滑即时，鼠标悬停即现，不阻断打字与标签切换。 |
| **未保存标题提取规则** | 智能首行有效行扫描 + Markdown 标题标记剥离 | 用户习惯第一行写文档总标题或大纲（如 `# 架构设计`），剥离符号后呈现最干净核心语义；跳过空行包容创作者随手排版。 | 哪怕连续打开 5 个 Untitled 草稿，鼠标一扫就能准确知道每篇写的是什么。 |
| **信息呈现载体** | 原生菜单 Help 项 + 偏好设置「关于」面板双通道 | 键盘流用户习惯在原生菜单（macOS 顶栏）查看，GUI 用户习惯在设置（`⌘,`）查看，双通道满足不同场景。 | 无论何种操作习惯，均能在 1 秒内找到版本号、项目地址与作者信息。 |
| **外链打开协议** | 主进程 `shell.openExternal` 强加协议白名单检验 | 防止直接在渲染进程调用未经校验的命令或伪协议引发安全漏洞。 | 桌面端极其安全，点击链接体验丝滑自然。 |
