# Release Note - mditor v0.2.0：全面对标 Typora 的真所见即所得双模式内核

## 1. 版本核心亮点

1. **真所见即所得（WYSIWYG）+ 源码双模式（`⌘/`）**：
   - 采用 Milkdown（ProseMirror + remark，CommonMark + GFM）作为实时渲染内核，结合 CodeMirror 6 纯源码模式，按 `⌘/` 或底部状态栏按钮毫秒级切换。
   - **局部语法定界符露出（Hybrid Inline Delimiter Reveal）**：光标进入标题或加粗、斜体、删除线、行内代码、链接内部时，仅在当前元素两侧淡色露出语法定界符，排版字号与行高 **0 跳变**。
   - **连续无缝纯白画布（Seamless Canvas）**：移除任何割裂视口的浮动卡片边框，提供与 Typora 完全一致的全屏沉浸连续画布与首行空文档占位符引导。
2. **原生级块级富组件交互（表格、代码块、图片、任务列表）**：
   - **表格**：实时渲染编辑、浮动操作工具栏（增删行列、左中右对齐、删除表格）、`Tab` / `⇧Tab` 跳格与末格自动增行、`⌥⌘T` 快捷插入指定行列数表格弹窗。
   - **代码块**：内嵌 CodeMirror 6 实时高亮编辑、右上角语言筛选切换、一键复制代码、`↑` / `↓` 边界丝滑跳出。
   - **本地与网络图片**：注册 Electron `local-file://` 安全特权协议，完美支持文档同级相对路径（`./assets/...`）、本地绝对路径与 `http(s)` 图片渲染；支持光标移入顶部胶囊源码修改及剪贴板粘贴自动落盘 `./assets/`。
   - **交互式任务列表**：GFM 任务列表 `- [ ]` / `- [x]` 渲染可点击切换的原生复选框，点击勾选直接同步更新底层 Markdown。
3. **Typora 经典侧边栏与沉浸式写作工具箱**：
   - **双视图侧边栏（`⇧⌘L`）**：顶部「文件 / 大纲」一键切换；打开本地文档自动扫描所在目录生成 `.md` 文件树，点击文件直接打开；大纲支持点击平滑跳转与正文滚动同步高亮（ScrollSpy）。
   - **专注模式（`F8`）与打字机模式（`F9`）**：专注模式自动淡化非当前顶层块（`opacity: 0.25`），打字机模式保持当前编辑行始终位于视口垂直中心。
   - **字数与阅读时长统计卡片（`WordCountPopover`）**：底部状态栏实时显示词数与字符数，点击展开预计阅读时间、词数、字符数（含/不含空格）、行数详情。
4. **源文件逐字节保真门禁**：
   - 定制 remark 序列化规则，通过 30+ 语料文件与真实企业级长文档保真回归测试。
