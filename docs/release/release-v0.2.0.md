# Release Note - mditor v0.2.0：全面对标 Typora 的真所见即所得双模式内核

## 1. 变更记录 (Changelog)

### Added
- **真所见即所得内核与双模式切换 (`⌘/`)**：引入 Milkdown (ProseMirror + remark) 渲染内核，支持 `⌘/` 快捷键毫秒级切换实时渲染与 CodeMirror 6 纯源码模式。
- **局部语法定界符露出 (Hybrid Inline Delimiter)**：光标进入标题或粗体、斜体、删除线、代码、链接时，仅在当前元素局部淡色露出语法符号，排版尺寸与行高 0 跳变。
- **GFM 表格交互增强**：所见即所得表格编辑、浮动工具栏（增删行列、单元格对齐）、`Tab`/`⇧Tab` 跳格与末格自动增行、`⌥⌘T` 弹窗快捷插入表格。
- **代码块内嵌高亮与跳出**：内嵌 CodeMirror 6 编辑区、语言下拉切换、一键复制代码、`↑`/`↓` 智能跳出。
- **本地图片特权流式加载与落盘**：注册 `local-file://` 协议，全面支持本地相对路径、绝对路径及剪贴板粘贴自动存入 `./assets/`。
- **交互式任务列表**：`- [ ]` / `- [x]` 复选框直接点击切换状态并同步回写 Markdown 源码。
- **Typora 双视图侧边栏 (`⇧⌘L` / `⇧⌘O`)**：支持「文件树」与「文档大纲」双视图无缝切换，大纲点击跳转与正文滚动实时高亮同步 (ScrollSpy)。
- **沉浸式写作辅助**：专注模式 (`F8`) 局部高亮、打字机垂直居中滚动 (`F9`)、底部状态栏字数统计与阅读时长卡片 (`WordCountPopover`)。
- **全局常用快捷键**：补齐 `⌘S` 快速存盘、`⇧⌘S` 另存为、`⌘O` 打开文件、`⌘N`/`⌘T` 新建标签、`⌘W` 关闭标签、`⇧⌘C` 一键复制公众号/知乎排版。

### Changed
- **无缝纯白画布**：移除旧版浮动卡片边框与阴影，恢复 Typora 一体化原生无缝打字手感。
- **顶栏 Tab 布局自适应**：移除标签栏最大宽度锁死，窗口最大化后标签栏自适应撑满，保持左侧紧贴 macOS 交通灯，顶栏空白区支持原生拖拽与双击缩放。

### Fixed
- **异步双实例挂载与光标跳动**：修复快速重挂载时由于 Ref 闭包失效导致的双 ProseMirror 实例并存及首行输入跳光标缺陷。
- **标题输入换行跳脱**：修复由于 Tailwind Preflight 将 `img` 全局重置为 `display: block` 导致 ProseMirror 光标分隔符强行换行的问题。
- **表格边框与样式重置**：补齐 GFM 表格实线网格、表头底色、斑马纹与单元格内边距，解决表格边框看不清问题。
- **新建空文档占位符**：解决空文档一片空白无法分辨编辑区的问题，增加首行占位提示与自动聚焦。

### Removed
- 废弃 v0.1.0 基于 CodeMirror 6 行内 Widget 装饰器的伪所见即所得方案，彻底消除行高闪烁与排版跳变。
