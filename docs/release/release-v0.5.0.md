# Release Note - mditor v0.5.0：工作区全局闪电检索、原生拖拽重排与出版级多格式导出

mditor v0.5.0 是一个集「大库闪电索引、界面自由布局、出版级交付」于一身的重磅生产力版本。本版本带来了媲美 Spotlight 的全局快速打开（`⌘P`）与跨文件全文检索定位（`⌘⇧F`），赋予了侧边栏宽度拖拉与文件/Tab 自由拖拽重排的灵动操作手感，并正式交付了防腰斩出版级 PDF 导出、原生 Word (`.docx`) 结构化导出以及画布图片沉浸式灯箱。

---

## 1. 核心特性与变更记录 (Changelog)

### Added
- **全局快速文件打开（Quick Open，`⌘P` / `Ctrl+P`，F31）**：
  - **Spotlight 风格居中浮层**：任意时刻按下 `⌘P`（macOS）或 `Ctrl+P`（Win/Linux）即可弹出快速搜索框，输入文件名或路径即刻流式模糊匹配；
  - **智能模糊评分与全键盘流转**：支持不连续字符匹配、子路径过滤（如 `src/index`）与最近访问排序；`↑` / `↓` 切换选中项，`Enter` 回车秒级打开或切换标签页，按 `Escape` 键平滑退出并归还编辑区焦点。

- **全工作区全文内容检索与微光定位（Workspace Full-Text Search，`⌘⇧F` / `Ctrl+Shift+F`，F32）**：
  - **专属搜索侧栏**：侧边栏扩展为「文件夹 / 大纲 / 搜索」三重视图，按下 `⌘⇧F` 一键展开并自动聚焦搜索框；
  - **高性能多文件并发检索**：极速扫描工作区内所有文本与代码文件（自动排除 `.git`、`node_modules` 等目录），支持区分大小写与整词匹配，提供上下文匹配行摘要；
  - **段落精准滚动与微光定位**：点击任意搜索结果行，自动打开对应文件并平滑滚动到目标行，瞬间赋予黄色高亮脉冲微光（Flash Highlight），让大文档检索一目了然。

- **侧边栏宽度自由拖拉调整与持久化（Resizable Sidebar，F30）**：
  - **弹性双向拖拽把手**：侧边栏右侧边缘内置平滑热区，鼠标悬停呈现优雅微光并切换为 `col-resize` 光标；
  - **防穿透边界与双击复位**：严格限定宽度区间为 `180px` ~ `520px`；双击把手瞬间精准复位至系统经典默认宽度（`240px`）；
  - **本地持久化无跳变**：调整结果自动保存至本地存储，应用重启与窗口重载保持零布局跳变（CLS 归零）。

- **侧边栏文件与文件夹跨目录拖拽移动（Drag & Drop File Move，F33）**：
  - **直觉式拖放移动**：文件树节点支持原生 HTML5 拖拽，悬停至目标文件夹时展示落点外发光与半透明高亮指示；
  - **循环嵌套安全拦截**：严格防御将父文件夹拖入其自身或其子目录的操作，杜绝文件系统死循环；
  - **底层原子移动与 Tab 级联同步**：释放后调用主进程执行安全路径变更；若被移动文件已在 Tab 打开，静默自动同步其标签路径，保存时不掉链。

- **顶栏 TabBar 标签页自由拖拽排序（Drag & Drop Tabs，F34）**：
  - 鼠标按住任意 Tab 即可左右拖曳，相邻标签页带物理流动动画让出占位；
  - 释放后即时重排内部标签页状态数组，文档脏标记与激活态完整保持。

- **出版级专业 PDF 导出引擎（Page Break Avoidance & Print Styling，F35）**：
  - **排版防断页保护**：在 `@media print` 中为代码块、GFM 数据表格、独立公式块、Mermaid 矢量图表以及各级标题注入 `break-inside: avoid` 与 `break-after: avoid` 规则，彻底根除代码与表格跨页被生硬腰斩的恶劣排版；
  - **多维版面定制**：导出选项模态框支持选择 A4 / Letter 纸张规格、标准（20mm）与窄边距（10mm），并可自主控制页眉标题与动态页码显示。

- **原生 Word 文档格式高保真结构化导出（Export to `.docx`，F36）**：
  - 在导出菜单中新增「导出为 Word 文档 (.docx)」选项；
  - 采用本地轻量 AST 转换引擎，将 Markdown 段落、各级标题、粗体斜体删除线、代码块（等宽字体+浅灰底衬）、GFM 表格（原生表格对象+表头加粗底色）、引用块（暖灰竖线）精准映射为 Microsoft Word 原生格式。

- **画布图片沉浸式大图灯箱（Image Lightbox Zoom，F37）**：
  - 图片右上角常驻精致「🔍 放大」浮标，点击浮标或图片本身即可唤出全屏暗黑玻璃灯箱；
  - 支持滚轮放大缩小（25% ~ 500%）、鼠标拖拽平移、原始比例复位，底部显示自然分辨率与当前缩放百分比；
  - 支持按 `Escape` 键或点击背景快速平滑退出。
