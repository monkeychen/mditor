# PRD-v0.5.0：工作区全局闪电检索、原生拖拽管理、自由侧边栏与出版级多格式导出

## 1. 版本背景与目标

在经历 v0.1.0 ~ v0.4.0 的持续迭代后，mditor 已经具备了极致丝滑的所见即所得打字手感、原生主题偏好设置、全能文本代码语法高亮以及多工作区文件夹的上下文右键管理体系。

然而，随着用户引入的真实项目和知识库规模从「单篇散落笔记」扩充到「成百上千篇长文与代码资料」，生产力交互链路中暴露出三大核心瓶颈：
1. **大库索引效率断层**：找文件只能依赖鼠标在折叠树中滚动翻找；全局缺乏 `⌘P` 模糊搜索文件名与 `⌘⇧F` 跨文件全文关键词检索能力；
2. **布局与交互死板**：侧边栏宽度固定（240px），在长文件路径或多层目录深处时文字被严重截断；文件无法在文件夹之间自由拖拽移动，顶栏 Tab 标签页无法拖动调整顺序；
3. **正式成果交付不足**：当前 PDF 导出缺乏分页控制（长代码块、长表格被截断切割），缺乏对商业协作最常用的 Word (`.docx`) 格式导出支持，文档内插入的图片无法点击放大查看细节。

**v0.5.0 核心定位**：将 mditor 从「单文档精细写作」全面跃升为**「海量文档秒级检索、自由拖拽重组、出版级全格式交付」的终极桌面级 Markdown 生产力工作台**。

## 2. 功能清单（Features）

### F30：侧边栏宽度自由拖拉调整与持久化（Resizable Sidebar）
- **AC-30.1（拖拽把手与交互反馈）**：
  - 侧边栏右侧边缘提供 4px 宽度的隐形拖拽热区，鼠标悬停时平滑浮现淡雅高亮条，光标切换为双向调整指示（`col-resize`）；
  - 拖拽过程采用防抖与实时宽度更新，编辑画布自适应缩放，无卡顿闪烁；
  - 设定合理的弹性边界保护：最小宽度为 `180px`，最大宽度为 `520px`；
  - 支持**双击拖拽把手**直接复位至系统经典默认宽度（`240px`）。
- **AC-30.2（本地状态持久化）**：
  - 侧边栏宽度改变时自动持久化至 `localStorage`（键名 `mditor_sidebar_width`）；
  - 应用重启或窗口重载时无缝恢复用户调整后的宽度，无布局跳变（CLS 归零）。

---

### F31：全局快速文件打开（Quick Open，`⌘P` / `Ctrl+P`）
- **AC-31.1（全局快捷呼出与居中浮层）**：
  - 无论处于何种视图或焦点状态，按下快捷键 `⌘P`（macOS）/ `Ctrl+P`（Windows/Linux）均可在窗口上方居中弹出 macOS Spotlight 风格的高灵敏度搜索浮层；
  - 支持 `Esc` 键或点击遮罩边缘即刻收起并自动将光标焦点归还编辑区。
- **AC-31.2（智能模糊匹配与拼音首字母支持）**：
  - 索引当前所有已添加的工作区文件夹内的全部文件（包括 Markdown、文本及代码文件）；
  - 采用轻量极速模糊评分算法（Fuzzy Match），支持连续/不连续字符匹配、路径匹配（如输入 `src/index`）以及中文拼音首字母匹配；
  - 匹配命中项在结果列表中高亮显示关键词命中字符，右侧显示相对工作区路径与格式徽标。
- **AC-31.3（全键盘无鼠标流转）**：
  - 键盘上下方向键（`↑` / `↓`）或 `Ctrl+N` / `Ctrl+P` 自由切换选中项；
  - 按下 `Enter` 回车键：若目标文件已在 Tab 中打开则直接平滑切换激活，若未打开则立即新建 Tab 加载并自动关闭搜索面板；
  - 若输入为空，默认展示最近打开或访问的历史文件列表（Recent Files）。

---

### F32：全工作区全文内容检索（Workspace Full-Text Search，`⌘⇧F` / `Ctrl+Shift+F`）
- **AC-32.1（专属侧边栏检索视图与快捷唤起）**：
  - 支持快捷键 `⌘⇧F`（macOS）/ `Ctrl+Shift+F`（Windows/Linux）一键展开侧边栏并自动切入「搜索」视图，搜索输入框自动获焦；
  - 侧边栏顶部切换选项卡扩展为三视图：**文件夹**、**大纲**、**搜索**。
- **AC-32.2（高性能全文检索与上下文预览）**：
  - 主进程通过流式或多线程并行扫描工作区目录下全部文本与代码文件（自动忽略 `.git`、`node_modules` 等无关目录）；
  - 搜索结果按文件聚合展示：显示文件名、命中次数、匹配行行号及命中词前后 60 字符的上下文代码/段落片段，命中关键词特殊高亮；
  - 支持区分大小写（`Aa`）、整词匹配（`\b`）等基础高级选项。
- **AC-32.3（精准段落滚动与行高亮）**：
  - 点击检索结果中的任意匹配行，自动在编辑器中打开对应文件，并将视口平滑滚动至该行，瞬间给予目标行 1.5 秒的黄色微光高亮脉冲（Flash Highlight），让用户一眼锁定检索目标。

---

### F33：侧边栏文件与文件夹跨目录拖拽移动（Drag & Drop File Move）
- **AC-33.1（拖拽视觉反馈与落点高亮）**：
  - 支持在侧边栏文件树中选中单个文件或子文件夹发起鼠标拖拽（HTML5 Drag & Drop）；
  - 拖拽悬停至目标文件夹节点时，目标节点呈现外发光边框与半透明落点指示（Drop Indicator）；
  - 严格限制非法落点：禁止将父文件夹拖入其自身或其子目录中（防止文件系统死循环）。
- **AC-33.2（底层原子重命名与 Tab 强同步）**：
  - 释放鼠标（Drop）后，通过 Electron 主进程原生执行文件/目录物理路径移动（`fs.rename`）；
  - 移动成功后自动刷新工作区目录树；
  - **Tab 强同步**：若被移动的文件（或被移动文件夹内部的文件）恰好在 Tab 标签中打开，静默无感将其 `filePath` 更新为移动后的新绝对路径，确保后续保存（`⌘S`）不会落空或误写到旧位置。

---

### F34：顶栏 TabBar 标签页左右拖拽排序（Drag & Drop Tabs）
- **AC-34.1（标签页拖拽位移与占位动画）**：
  - 鼠标按住任意 Tab 标签可左右拖动，被拖动的 Tab 呈现微浮起半透明状态；
  - 相邻 Tab 随拖拽位移平滑让出空位，提供丝滑的物理流动手感；
- **AC-34.2（状态数组同步）**：
  - 释放鼠标后，`useTabs` 内部维护的标签页顺序数组立即持久重排，激活态与未保存脏状态（Dirty）完好保持。

---

### F35：出版级 PDF 导出引擎（Page Break Avoidance & Headers/Footers）
- **AC-35.1（分页保护与智能防断页）**：
  - 针对打印与 PDF 导出专用样式（`@media print`）注入全局防断页规则；
  - 确保**代码块（Code Block）、GFM 数据表格（Table）、独立公式块（Math Block）、Mermaid 矢量图表以及二级以内标题与其后续首段**严格遵循 `page-break-inside: avoid` / `break-inside: avoid`，彻底根除代码跨页被生硬腰斩的恶劣排版体验。
- **AC-35.2（页面布局与页眉页脚控制）**：
  - 导出对话框提供纸张规格（A4、Letter）、边距（标准 20mm、窄边距 10mm）；
  - 支持开关页码（如 `第 X 页 / 共 Y 页`）与文档标题页眉。

---

### F36：原生 Word 文档格式导出（Export to `.docx`）
- **AC-36.1（高保真结构化导出）**：
  - 在导出菜单中新增「导出为 Word 文档 (.docx)」选项；
  - 基于 AST 结构化转换引擎，将 Markdown 解析生成的段落、1~6 级各级标题、粗体/斜体/删除线、无序/有序列表、任务清单、引用块完整映射为标准 Word 段落样式；
  - GFM 表格自动映射为 Word 原生表格对象（含表头加粗底色与边框）；
  - 代码块以等宽字体与深灰底色容器块嵌入，公式与本地图片完整内嵌进 `.docx` 包中，保证在 Microsoft Word / WPS Office 中打开排版精美。

---

### F37：画布图片灯箱大图预览（Lightbox Image Zoom）
- **AC-37.1（图片点击放大与手势缩放）**：
  - 在所见即所得画布中，点击图片右上角出现的「🔍 放大」浮标或双击图片本身，即刻呼出沉浸式深色全屏灯箱（Lightbox）；
  - 支持滚轮放大/缩小、拖拽平移、点击遮罩或按 `Escape` 键平滑退出；
  - 底部显示图片原始文件名、自然分辨率（Natural Dimensions）与缩放比例。

## 4. 非目标（v0.5.0 暂不包含）

1. 在 Word (`.docx`) 导出中支持复杂宏（VBA Macros）与复杂排版插件；
2. 云端远程 Elasticsearch / 向量全文数据库连接（坚持 Local-first 本地优先，检索全由本地轻量流式 IO 驱动）；
3. 任何侵犯 Typora 商标、内置 CSS 的行为（严格遵守 `GEMINI.md` 红线）。
