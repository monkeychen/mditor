# PRD-v0.3.1：Windows 升级体验优化、CI 管道加固与 KaTeX 原型级公式编辑器

## 1. 背景与目标

在 v0.3.0 发布后，经实际使用发现：
1. KaTeX 数学公式编辑交互与高保真原型存在严重偏差，缺少事件拦截与独立实时预览容器，退格与按键易引发节点误删，基本不可用；
2. GitHub Actions 多 Runner 并发请求写竞争，导致 Windows 安装包被意外孤立上传至未关联 Tag 的 Draft Release；
3. Windows NSIS 安装程序在覆盖安装时缺乏对已安装旧版本的显式检测与弹窗告知。

v0.3.1 作为维护补丁版本，目标是：
1. **全面对齐 KaTeX 数学公式系统与原型视觉交互**：独立公式块双态卡片、正下方实时渲染卡片、行内公式悬浮弹层与事件隔离；
2. **固化 CI/CD 发布流程**：消灭并发写竞争，实施全平台产物硬门禁；
3. **完善 Windows 安装向导**：实现旧版安装检测、版本号提取、友好弹窗提示及旧程序文件清理，确保用户数据 100% 安全。

---

## 2. 用户故事

- **作为理工科重度学术写作者**，当我编辑数学公式时，我希望能拥有与设计原型一致的高保真视觉与交互体验：点击公式块即可展开精美编辑面板，在文本域下方实时观察公式矢量排版，输入退格与换行顺畅不卡顿、不误删，使公式编写如丝般顺滑。
- **作为 Windows 用户**，当我在已有旧版本电脑上双击新版本安装包时，我希望能清晰获知已检测到旧版本、系统将自动清理旧版程序文件并保留我的文档与个人设置，以便我安心无忧地升级。
- **作为跨平台用户与维护者**，每次发版时，我希望能保证 macOS、Windows、Linux 三大平台的安装包完整、可靠、无遗漏地由云端 CI 自动挂载至 GitHub Release。

## 3. 功能需求

### F23：Windows NSIS 安装前旧版本检测与安全升级
- **AC-23.1 [检测与提示]**：NSIS 安装向导在 `customInit` 阶段从注册表读取 `com.mditor.app` 的 `UninstallString` 与 `DisplayVersion`。若检测到旧版本，弹出系统对话框告知用户已安装旧版本，并说明升级策略（自动清理旧程序文件、完整保留个人数据）。用户选「是」继续，选「否」退出。
- **AC-23.2 [安全清理与数据隔离]**：执行升级时，安装程序自动清理旧版本二进制文件；`electron-builder.json` 显式设置 `deleteAppDataOnUninstall: false`，确保 `%APPDATA%\mditor` 下的用户文档缓存与主题偏好完好保留。

### F24：CI/CD 单锚点构建与全平台资产硬门禁
- **AC-24.1 [单锚点消除竞态]**：发布流水线在多平台 Matrix 启动前，由单节点 Job `prepare-release` 先行向 GitHub API 创建唯一的 Draft Release 作为锚点，三平台 Runner 统一向该锚点挂载产物，根除并发写竞争。
- **AC-24.2 [全平台资产硬门禁]**：`finalize-release` 在正式发布 Release 前，强制校验资产列表必须同时包含 `.dmg`（macOS）、`.exe`（Windows）、`.AppImage`（Linux）。缺失任何一项，CI 立即报错退出（`exit 1`），拒绝发布半成品。

### F25：KaTeX 数学公式原型级交互编辑器
- **AC-25.1 [独立公式块双态卡片]**：
  - **展示态**：居中大字号矢量公式渲染 + 底部 `TeX 源码: ...` 预览条与 `点击展开交互编辑面板 ▾`。
  - **展开态**：完全对齐原型视觉：顶部蓝调标题栏（`📐 独立公式块编辑器` + `DisplayMode` 徽章 + `复制代码` / `收起 ✕`）、多行 LaTeX 编辑文本域、正下方独立实时公式矢量预览卡片、右下角 `完成` 动作按钮。
- **AC-25.2 [行内公式悬浮弹层与实时预览]**：点击行内公式弹出悬浮编辑卡片（`✏️ 正在编辑行内 LaTeX 公式`），包含 `$` 包裹输入框、`应用` / `取消` 快捷按钮及 `实时预览` 矢量渲染槽；修改即时联动。
- **AC-25.3 [ProseMirror 事件隔离与输入规则]**：引入 `stopEvent` 与 `ignoreMutation` 彻底隔离编辑期间的按键冒泡，杜绝退格/回车引起节点误删；支持 `$formula$` 行内公式实时转换输入规则。

## 5. 非目标
- 不变更通用 Markdown 核心语法（表格、列表、引用等已在 v0.2.0 完成）。
- 不引入第三方封闭数学引擎，全链路坚持 KaTeX 开源高精渲染。
