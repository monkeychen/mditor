# PRD-v0.1.0: 跨平台 macOS 质感沉浸式 Markdown 编辑器 (mditor)

## 1. 背景与目标
当前许多 Markdown 工具在跨平台与原生手感之间存在妥协：基于纯 DOM 富文本的工具容易篡改原 Markdown 语法且长文卡顿；而传统分屏编辑器破坏了专注沉浸感。本项目旨在打造一款结合 macOS 顶级原生审美与 CodeMirror 6 纯文本高性能的跨平台 Markdown 编辑器，为写作者和开发者提供即时所见即所得（Live Preview）、零输入延迟、本地绝对受控的创作体验。

---

## 2. 用户故事
- **As a** 深度创作者/程序员
- **I want** 在一个极简、无标题栏干扰、具有 macOS 精致排版的单窗口中编写 Markdown，光标移开即渲染、光标进入即编辑，并且可以方便地管理多个文档标签、拖拽插入本地图片与一键导出到公众号或 PDF
- **So that** 我无需忍受传统左右分屏预览的注意力割裂，不用担心富文本编辑器破坏源文本格式，能够以最高信噪比和最丝滑的手感沉浸写作。

---

## 3. 功能需求与验收标准

### F1: macOS 风格窗口与多标签页（Tab）系统
- **AC1.1**: 窗口采用隐藏原生标题栏（`titleBarStyle: 'hiddenInset'`），保留 macOS 红绿灯交通灯按键，并在左上方正确留出避让间距与可拖拽区域。
- **AC1.2**: 支持多标签页（Tabs）管理：每个标签显示文档标题、修改未保存标记（圆点指示符）与关闭按钮。
- **AC1.3**: 快捷键支持：新建标签（`Cmd/Ctrl+T`）、关闭当前标签（`Cmd/Ctrl+W`）、在标签间快速切换（`Cmd/Ctrl+1..9` 或 `Cmd/Ctrl+Shift+[` / `]`）。
- **AC1.4**: 关闭存在未保存修改的标签页时，系统弹出阻断确认框（保存/放弃/取消）。

### F2: CodeMirror 6 驱动的即时所见即所得编辑器（Live Preview）
- **AC2.1 标题渲染**：1-6 级标题在光标移出该行时，隐藏 `#` 前缀并以对应层级字号与字重呈现；光标移入该行时，立即平滑显现 `#` 符号及原始标记。
- **AC2.2 行内样式**：`**加粗**`、`*斜体*`、`~~删除线~~`、`` `行内代码` ``在光标脱离时隐藏定界符并展现排版样式；光标移入对应文本区间时展现定界符。
- **AC2.3 列表与任务项**：支持无序列表、有序列表与任务列表（`- [ ]` / `- [x]`）。任务列表 checkbox 处于渲染态时可直接鼠标点击切换勾选状态，且底层 Markdown 文本同步切换。
- **AC2.4 引用块与分割线**：引用块（`> `）呈现精美竖线引导条，分割线（`---`）光标离开时渲染为横向平滑分割线。
- **AC2.5 代码块高亮**：围栏代码块（```lang）在离开时渲染为独立代码背景卡片，具有语法高亮（至少覆盖 js/ts/python/json/html/css/sh/md），右上角具备一键复制代码按钮。
- **AC2.6 极致性能与纯文本保真**：采用 CodeMirror 6 的 ViewPlugin / StateField Decoration 体系，禁止修改底层文本字符；十万字长文档滚动与打字保持 60fps 无掉帧。

### F3: 本地文件系统操作与持久化
- **AC3.1 打开文件**：支持通过菜单栏、快捷键（`Cmd/Ctrl+O`）或将 `.md` / `.markdown` / `.txt` 文件拖拽入窗口打开，文件内容在新标签页载入。
- **AC3.2 保存与另存为**：支持快捷键保存（`Cmd/Ctrl+S`）与另存为（`Cmd/Ctrl+Shift+S`）。未命名新建文档首次保存呼出原生文件保存对话框。
- **AC3.3 自动保存（Auto Save）**：支持文档内容变更后防抖（1.5 秒）自动写回本地磁盘，UI 提供保存状态指示（“已保存” / “保存中”）。

### F4: 本地图片自动管理与落盘
- **AC4.1 剪贴板图片粘贴**：支持从剪贴板直接粘贴图片（`Cmd/Ctrl+V`），程序自动在文档所在目录的 `./assets/`（未保存文档保存在全局临时缓存目录）生成以时间戳命名的 PNG 文件，并在光标处插入 Markdown 图片语法 `![image](./assets/xxx.png)`。
- **AC4.2 外部图片拖拽**：支持将本地文件系统的图片文件直接拖入编辑区，自动完成拷贝到 `./assets/` 并插入语法。
- **AC4.3 图片内嵌渲染**：编辑器内直接以行内/块级方式自适应缩放展示图片，支持光标选中与右键复制文件路径。

### F5: 文档结构大纲（Outline / TOC）抽屉导航
- **AC5.1 大纲树提取**：即时响应文档变化，提取所有 H1-H6 标题构建树状/缩进大纲。
- **AC5.2 平滑定位**：点击大纲项，编辑器视图平滑滚动并将光标移至对应标题起始行。
- **AC5.3 视口跟踪**：编辑器视口滚动时，大纲侧边栏自动高亮当前所在章节的标题。
- **AC5.4 展开与折叠**：提供左侧抽屉开关按钮与快捷键（`Cmd/Ctrl+Shift+O`），支持展开与隐藏大纲。

### F6: 快捷查找与替换（Search & Replace）
- **AC6.1 查找框交互**：按 `Cmd/Ctrl+F` 唤起悬浮搜索栏，支持实时统计匹配结果数（如 `3/15`）并高亮全篇匹配项。
- **AC6.2 快速跳转**：支持 `Enter` / `Shift+Enter` 或上下箭头按钮在匹配项间快速跳转。
- **AC6.3 替换支持**：支持展开替换输入框（`Cmd/Ctrl+H` 或 `Cmd/Ctrl+Alt+F`），支持单次替换与一键全部替换。

### F7: 多格式导出与微信公众号排版复制
- **AC7.1 导出 HTML**：将当前 Markdown 及渲染样式打包为单一独立 `.html` 文件，支持排版样式完全自包含内嵌。
- **AC7.2 导出 PDF**：调用 Electron 打印管道生成规范的 PDF 文件，具备分页与精致打印排版。
- **AC7.3 复制为公众号/知乎富文本**：一键将当前渲染结果转换为标准带内联样式（Inline CSS）的 HTML 写入剪贴板，用户直接粘贴至微信公众平台、知乎等富文本编辑器无样式损耗。

## 4. 里程碑划分

| 里程碑 | 目标 | 覆盖 F / AC | 涉及前端 UI（需 Prototype） | 外部系统/接口依赖 |
|---|---|---|---|---|
| **M1** | 核心骨架、CodeMirror 6 实时渲染与基础文件读写 | F1 (AC1.1), F2 (AC2.1, AC2.2, AC2.3, AC2.4, AC2.6), F3 (AC3.1, AC3.2, AC3.3) | 是 | 本地文件系统 IPC |
| **M2** | 多标签页系统、本地图片自动落盘与大纲导航 | F1 (AC1.2, AC1.3, AC1.4), F4 (AC4.1, AC4.2, AC4.3), F5 (AC5.1, AC5.2, AC5.3, AC5.4) | 是 | 剪贴板图像读写、文件目录操作 |
| **M3** | 快捷查找替换、高级语法扩展与多格式导出 | F2 (AC2.5 高级代码块), F6 (AC6.1, AC6.2, AC6.3), F7 (AC7.1, AC7.2, AC7.3) | 是 | 系统打印管线 (PDF)、剪贴板富文本写入 |

## 5. 非目标（Out of Scope for v0.1.0）
1. 不做复杂的双向链接与全局知识网络图谱（留待知识库版本迭代）。
2. 不内置私有云端账号系统与同步服务器（完全基于本地文件，自然兼容 iCloud Drive、Dropbox、OneDrive、Git）。
3. 不开发第三方插件平台与动态脚本市场。
4. 不支持多端实时协同冲突解决（CRDT / OT）。
