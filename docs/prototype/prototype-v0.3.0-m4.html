第一章：系统设计哲学

系统设计的第一性原理是：后端可以很复杂，但用户触碰到的每一层必须丝滑。 无论是排版渲染、公式编辑、还是多主题无感切换，界面响应时间必须被严密控制在人体知觉阈值之内。
